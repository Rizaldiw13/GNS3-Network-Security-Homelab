# Configuration Files

This directory contains saved configuration files for the routers and infrastructure services used in the GNS3 Network Security Homelab.

The purpose of this folder is to keep the lab configuration version-controlled, readable, and easy to reference during troubleshooting or future rebuilds.

## Files

### VyOS Routers

- `R1-config.txt` — VyOS configuration for R1
- `R2-config.txt` — VyOS configuration for R2
- `R3-config.txt` — VyOS configuration for R3

These files are generated from:

```text
show configuration commands
```
